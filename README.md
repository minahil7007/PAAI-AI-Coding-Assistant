# PAAI — AI Coding Assistant

PAAI (Personal AI Assistant) is a Windows desktop AI coding assistant built with C#, .NET 8, and WPF. It helps developers analyze code, detect development errors, understand problems, and get AI-assisted solutions through Claude API integration. The application also supports project monitoring, browser and terminal error detection, code analysis, and controlled AI-generated fixes with a preview before changes are applied.

## Tech Stack

C#, .NET 8, WPF, Claude API, Microsoft Roslyn, Microsoft Playwright, and NAudio.

## Getting Started

Requires Windows, .NET 8 SDK, and a Claude API key.

```bash
git clone https://github.com/minahil7007/PAAI-AI-Coding-Assistant.git
cd PAAI-AI-Coding-Assistant
dotnet run
```
